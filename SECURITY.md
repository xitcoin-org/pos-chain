# Security policy

## Reporting a vulnerability

Do not publish vulnerabilities, private keys, mnemonics, passwords or infrastructure details in a public issue.

When the GitHub repository is published, private vulnerability reporting will be enabled through GitHub Security Advisories. Until then, no public security-reporting channel is announced.

## Scope

Security reports may concern the Xitcoin chain source code, build process, public testnet software or published documentation.

Private validators, private testnet infrastructure and external services are out of scope for public disclosure.
