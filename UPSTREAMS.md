# Upstream attribution

Xitcoin is built on open-source software from the Cosmos ecosystem.

The codebase includes and derives from components of:

- Cosmos SDK
- CometBFT
- IBC-Go
- Cosmos EVM
- evmOS and its predecessor work

Their licenses, notices and attribution requirements remain in force. Xitcoin does not claim authorship of upstream software.

Upstream project documentation and source repositories should be consulted for their respective maintenance and security policies.
